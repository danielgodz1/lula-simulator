# 🇧🇷 Lula Simulator

O simulador e jogo do Lula com:
- **Flappy Lula 2D** (`jogo.html`)
- **Empresário 3D** (Three.js WebGL em `correr.html`)
- **Ranking & Feedbacks** (Integrado ao Firebase Firestore em `ranking.html` e `feedback.html`)
- **Página de Contato** (`contato.html`)

## 🚀 Como Executar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador ou rodar um servidor local (ex: Live Server ou `npx serve .`).
